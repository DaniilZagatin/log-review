# Запуск Белки

Подготовка окружения и полный пример команды находятся в [README.md](README.md).

1. Установите Python 3.11+ и зависимости: `python -m pip install -e .`.
2. Настройте модель в `.env`, используя [.env.example](.env.example).
3. Передайте краткое описание **одного варианта сценария** и несколько источников кода в `pko map-scenario`.
4. Откройте `scenario-map-out/scenario_map.html`. Проверьте границы, операции, связи и обозначенные пробелы.

Все параметры: `python -m pko.cli map-scenario --help`.
Учебная карта без вызова модели: `python scripts/demo_scenario_map.py`.
Проверки: `python tests/run_tests.py`.

Коды выхода: 0 — completed, 2 — partial, 1 — ошибка, 130 — прервано. Completed означает выполнение проверок карты, а не гарантированную полноту анализа кода.

Старые команды progress/parse/initiatives/answers удалены. Реальные настройки `.env` сохранены; прежние переменные подключения PKO_MATCHER_* / PKO_ASSEMBLER_* остаются резервными именами. Для новой настройки используйте PKO_SCENARIO_*.
