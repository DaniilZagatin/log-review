# Приёмка C1–C3

27 октября 2026. Локальная спецификация входа «исходники + необязательное бизнес-описание» завершена в пределах C1–C3. Это не приёмка живой модели или официальная постановка процесса на учёт.

## Что принято

- **C1:** `export-onboarding` собирает из сохранённого запуска `process.md`, `onboarding.json`, словарь событий, доработки логирования, определения метрик и контрольные суммы. Никаких новых вызовов модели, чтения целевой репы или изменений исходного запуска. Частичный запуск остаётся частичным; CSV незавершённой стадии не выдаётся как пустой успешный результат.
- Ключ из предложенного сопоставления карты не называется доказанно существующим: `mapped_key` / `from_process_map`. Наличие статического вызова отражается отдельным полем. `existing_fields` сохраняет точные имена полей из соответствующих мест; словарь также есть в JSON. Предлагаемые новые события отделены; join/enrich и текст описания не превращаются в новые ключи.
- **C2:** все E01–E21 сопоставлены с конкретными проверками и их пределами; 81 точная ссылка на тестовый метод существует. Контрактная проверка, сценарный прогон, отображение, качество живой модели и корпоративная проверка разделены. Сценарии, которым нужны записи выполнения или история, не объявлены пройденными.
- **C3:** инструкции OpenCode/PILOT/README содержат последовательность probe → plan-only → analyze → resume при необходимости → export-onboarding → feedback. Новые документы включены в allowlist упаковщиков. Изменение целевого приложения не выполняется.

При независимой проверке исправлены два ошибочных ожидания новых тестов: словарь должен содержать и предложения событий; причина частичного разбора может одновременно содержать несколько блокеров. Их проверки сохранены с корректными ожиданиями. Codex также запрещает скрывать неполный scope противоречащим ему флагом полноты, убрал необоснованный статус `exact_source_key`, добавил найденные имена полей и включил новые справки в упаковку. Claude не запускал тесты; приведённые результаты получены Codex после его завершения.

Открытие CSV в настоящем Excel, Windows, корпоративные endpoint/TLS handshake и семантическое качество на реальной репе здесь не проверялись. Статические тесты кодирования не являются проверкой всех табличных приложений. Произвольные количественные утверждения в свободном тексте модели не распознаются автоматически; E21 принят только в указанной в матрице части.
