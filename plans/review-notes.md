# Проверка плана

Дата: 26 октября 2026 года.

Claude подготовил независимое предложение по контексту проекта, затем прочитал сводный план версии 0.1. Вердикт рецензии: «готов с конкретными изменениями»; критических архитектурных замечаний нет. Codex проверил существенные утверждения по сохранённым исходникам PKO и уточнил план до версии 0.2. Повторного одобрения версии 0.2 моделью не заявляется.

| Замечание | Решение в версии 0.2 |
|---|---|
| Выдача чувствительных данных через цитаты, feedback и ошибки | Сырая проверка остаётся локальной; безопасная цитата + хеш диапазона; один контур выдачи и canary-проверки всех каналов |
| Непонятное основание known_zero | Добавлены reference_data и независимое основание о возможностях выполнения; ноль событий не доказывает ноль выполнений |
| Слабая содержательная приёмка первого прохода | Ground truth отделён от конвейера; fake привязан к fingerprints; мутационная проверка результата и якоря |
| Модель может присвоить доверенные статусы | Закрытая граница trust, отдельный decisions input, кандидаты proposal/upstream не становятся принятыми обязательствами |
| Скрытая зависимость S03 от S02 | S03 использует протоколы и дерево в памяти; anchors проверяются при S04 |
| Endpoint блокирует offline-разработку | Протокол/fake/mock в S03; отдельная условная контрольная точка S03-L до пилота |
| Сложность навигации и кеша | Один дополнительный раунд чтений, без универсального loop; deterministic stages пересчитываются, кешируется только точный ответ модели |
| Условные поля не проверены | Добавлен E19; applicability unknown не превращается в нарушение |
| Git/regex helpers приняты по имени | Литеральный поиск; фиксированные безопасные Git-операции; запрет произвольных флагов и внешних программ |
| Необъявленные политики и новые числа в инсайтах | Явный default либо blocker; числа выдаёт код из рассчитанных артефактов |
| Установка может скрыто требовать сеть | Основные проверки через PYTHONPATH, Python 3.11+; установка отдельно |
| Корневой prompt смешан с runtime prompt | Runtime-промпты внутри пакета; запрос другому агенту остаётся в корневом prompts |

Дополнительно зафиксировано `scope_provisional` для неизвестного состава обязательств, чтобы полное покрытие найденных фактов не выдавалось за полноту процесса.

Это рецензия документа и целостности workspace. Код приложения и его тесты ещё не реализованы, реальный пилот не проводился. Служебные брифы/ответы и подтверждение фактической модели лежат локально в `.local/` и не входят в Git.
