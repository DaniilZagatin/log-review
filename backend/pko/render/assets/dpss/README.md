# ДПСС — шрифты паспорта

SB Sans Display 400/600/700 взяты из предоставленного пользователем архива
«Дизайн-система ДПСС (Claude Design).zip», каталог `ДПСС-кит/assets`.
Файлы не изменены. Это фирменные материалы пользователя, не самостоятельный
открытый шрифтовой пакет; отдельная лицензия в архиве не приложена.

Рендерер встраивает WOFF2 в HTML: внешние запросы и установка шрифта не нужны.
Цветовые токены и компоненты паспорта находятся в `_INLINE_CSS` модуля
`client_journey_passport.py`. Макеты слайдов и редакторские скрипты из архива
не переносятся в паспорт.
