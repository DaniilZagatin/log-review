# СберКот

Маскот: серо-сиреневый кот в зелёном костюме. Изображения оптимизированы под сайт (WebP с прозрачным фоном, до 800 пикселей; широкие кадры на волне 900×563 без прозрачности). Компонент `Mascot` подставляет нужную позу по имени.

| Файл | Поза | Где уместна |
|---|---|---|
| `sbercat-advisor.webp` | показывает рукой | подсказка, онбординг, «как это работает» |
| `sbercat-executive.webp` | лапы на столе | ожидание, пустое состояние, приём заявки |
| `sbercat-arms-crossed.webp` | скрещённые руки | правило, нет доступа, подтверждение |
| `sbercat-choice-left/center/right.webp` | две таблетки (синяя и зелёная) | выбор из двух вариантов; левая и правая позы подсвечивают вариант |
| `sbercat-host.webp`, `sbercat-standing.webp` | в рост, руки скрещены | приветствие, страница «О продукте» |
| `sbercat-sad.webp`, `sbercat-sad-eyes.webp`, `sbercat-upset.webp` | грусть, лапы на глазах, расстройство | сбой, 404, отказ |
| `sbercat-surf.webp`, `sbercat-surf-cool.webp` | на волне | успех, «всё готово», редкий декор страницы |

Правила: по умолчанию маскота нет — только редкий осознанный акцент (пустое состояние, ошибка, первый запуск), никогда внутри ответов и чата; не больше одного на экран; не в навигации, шапке, платёжных и юридических блоках; не перекрашивать и не обрезать. Нужной позы нет, закажите её, а не рисуйте.

В набор не вошли дубликаты и вырезанные лапы с таблетками (`paw-left`, `paw-right`: у них артефакты по краю) и исходники большого размера; они остались в папке `sbercat-all-20261020`.
