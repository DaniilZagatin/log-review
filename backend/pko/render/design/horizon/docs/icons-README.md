# Иконки

Набор иконок СберТеха (UI Kit CE): 4 928 глифов на сетке 24 с заливкой. Здесь лежат файлы SVG 87 основных иконок под смысловыми именами (`arrow-right.svg`, `check-circle.svg`, `zap.svg`) и вся библиотека одним файлом.

- `sbertech-icons.json` — все 4 928 глифов: `{ "имя": "d1|e:d2" }`. Имена в исходном виде без префикса `icon_sbertech_` (`credit_card`, `chart_pie`); `|` разделяет контуры одного глифа, префикс `e:` означает `fill-rule="evenodd"`; варианты `_filled` (активное состояние) и `_off` (перечёркнутая версия). Числа округлены до сотых. Подключение в коде: `fetch('assets/Icons/sbertech-icons.json').then(r => r.json()).then(Horizon.Icon.register)`.
- Компонент `Icon` уже содержит около 900 имён (все односложные, их `_filled`, смысловые синонимы); остальные берите через `Icon.register`.
- Цвет глифа задаёт `currentColor`; в файлах SVG стоит `#0a0a0f` как значение по умолчанию.
