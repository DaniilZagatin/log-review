# Типографика

Один гротеск (`sans`, Inter) и один моноширинный (`mono`, JetBrains Mono) для служебных меток. Кириллица и латиница в одном начертании.

## Принципы

1. Контраст размера, а не веса. Заголовок огромный и средний по весу (500), текст — обычный (400). Вес 300 — только у заголовков экранов приложения и у метрик.
2. Трекинг сжимается с размером: −0.01em у лида, −0.025em с 28px, −0.035em с 48px, −0.045em у hero 88px.
3. Строки коротки: заголовок до 16 знаков на строку в hero, лид до 52, абзац до 68. Используйте `text-wrap: balance` для заголовков и `pretty` для лидов.
4. Числа в таблицах и метриках — табличные (`font-variant-numeric: tabular-nums`).

## Шкала

| Стиль | Размер / межстрочный | Где |

| `display-lg` | 56 / 58 | Призывы к действию |
| `heading-xl` | 48 / 52 | Заголовки секций |
| `heading-lg` | 40 / 44, вес 300 | Заголовок экрана приложения |
| `heading-md` | 32 / 38 | Карточки, большой список опций |
| `heading-sm` | 28 / 40 | Ссылки мега-меню |
| `title` | 24 / 30 | Заголовки модалок и блоков |
| `lead` | 20 / 30 | Вводный абзац |
| `body-lg`, `body` | 19 / 28, 16 / 24 | Чтение |

| `eyebrow`, `mono-sm` | 12 / 11, mono | Верхняя метка раздела, BETA |

## Метрика с единицей

Число — `numeral` (вес 300), единица — 0.6 размера и `ink-tertiary`, отступ 0.25em: «98 %», «72 мин», «4,2 млн». Так читается сначала величина, потом смысл.

## Шрифт

Inter подключается из Google Fonts через `bundle.css` (веса 300–600, кириллица и латиница в одном файле). Референсы набраны проприетарными гротесками (у OpenAI на русской версии это OpenAI Sans с собственной кириллицей); Inter выбран как свободный аналог с полноценной кириллицей и теми же приёмами: вес 500, трекинг −0.03em от 28px. Без сети подставляются Helvetica Neue и Arial, в них тоже есть кириллица. Файлы шрифтов не входят в систему: подключите собственные, добавив их в `fonts/` и `type.fonts`.
