# Этап: необходимые бизнес-факты

Для вопросов измерения определи бизнес-факты, без которых на них нельзя ответить. Факт — то, что должно быть зафиксировано о конкретном экземпляре процесса: заявка принята, решение об отказе принято, карта выпущена, попытка отправки повторена.

Для каждого факта (`f-1`, `f-2`, …, не больше 30):

- `meaning` — что именно зафиксировано, предметным языком.
- `question_ids` — вопросы измерения, которым нужен факт.
- `lifecycle` — какая граница жизненного цикла нужна: `request`, `queued`, `start`, `result`, `refusal`, `error`, `retry`, `cancellation`, `compensation`, `state_change`. Начало не покрывает завершение; запрос не доказывает результат; повтор попытки не равен новому экземпляру.
- `operation_ids` — операции карты, в которых факт возникает. Если факт лежит вне приложения (оценка клиента, обращение в поддержку), оставь список пустым, поставь `outside_application=true` и объясни источник в `rationale`.
- `applicability` — `applicable`, `conditional` (укажи `condition`) или `unknown`.
- `needed` — что нужно знать о факте: `case_id` (к какому экземпляру относится), `timestamp` (когда произошло), `result`, `reason`, `actor`, `channel`, `amount`, `other`. Только то, что требуется вопросам этого факта.
- `observed_by` — идентификаторы подтверждённых записей из `event_bindings`, которые фиксируют этот факт. Запись подходит, только если её операция входит в `operation_ids` факта, а роль соответствует нужной границе.
- `field_sources` — для каждого нужного свойства, которое уже есть в записи: `purpose`, `binding_id` из `observed_by` и `field` — имя из полей этой записи.
- `rationale` — почему факт нужен и что потеряет измерение без него.

Если передан `domain_field_catalog`, используй его как справочник того, какие свойства событий бывают нужны. Это не обязательная схема: требуй только то, что нужно вопросам этого процесса.

Не создавай факты ради полноты списка и не дублируй один факт для разных вопросов: укажи несколько `question_ids`. Отсутствие подходящей записи не повод выдумывать её: оставь `observed_by` пустым.
