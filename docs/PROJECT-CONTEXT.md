# Контекст проекта

Актуально: 29 октября 2026. Этот документ содержит текущие решения; прежнее описание четырёх стадий сохранено в `.local/context-history-20261029/PROJECT-CONTEXT.md`.

## Продукт

Два агента последовательно работают по одному репозиторию:

1. Первый строит бизнес-карту по коду и бизнес-контексту: операции, переходы, крупные блоки, источники и пробелы. Сохраняет `scenario_map.json`, `map_hierarchy.json`, контекст и прочитанные фрагменты. Производное бизнес-описание не является ground truth.
2. Наш агент использует готовую карту: находит существующие записи, сопоставляет их с операциями, считает покрытие и предлагает адресные доработки. Не перестраивает карту и не проводит повторный полный LLM-разбор кода.

Метрики бизнеса заморожены. Новый архив отложен пользователем. Старый четырёхстадийный CLI сохранён для совместимости, но не определяет новый поток.

## Результат и интерфейс

Разделы: «Карта», «Логирование», «Доработки». Карта использует доверенный renderer первого агента с отдельным слоем покрытия: исходные ID и переходы не меняются. Крупные блоки раскрываются в атомарные операции; есть общий уровень детализации, выбор операции, инспектор, связи и режим окраски по логированию. Полный реестр несопоставленных кандидатов сохраняется.

Логирование показывает существующие полезные записи с кодом и смыслом. Доработки объясняют что изменить, зачем, какие данные нужны, где и как проверить. SYSTEM и содержательные примеры второго агента — на русском; JSON-ключи, enum, код, пути и исходные сообщения сохраняются точно.

## Покрытие

- C — достаточная существующая запись для смысла операции по коду.
- P — частичная запись, поиск завершён; U — подходящей записи не найдено после завершённого поиска.
- X — оценка не завершена, источники недоступны или есть конфликт. X не означает отсутствие логов.

N — все атомарные операции карты; группы N не увеличивают. C+P+U+X=N. Диапазон непокрытия: 100×(P+U)/N … 100×(P+U+X)/N. Предложения не повышают текущее покрытие.

## Основания и границы

Цитата подтверждает текст, а не бизнес-смысл, выполнение, коммит или доставку. Запрос/начало/ошибка/повтор/no-op не доказывают новый успешный эффект иной операции. Runtime-вопросы отделены от незавершённого поиска кода.

Java-навигация использует типы и точные вызовы. Неоднозначные цели остаются подсказками. Для нестандартного адаптера модель может интерпретировать интерфейс и реализацию; хост проверяет путь и прочитанные цитаты, сохраняет автора оценки и ограничения. Имя метода само по себе не доказывает журналирование.

Исследуемый код и входной HTML только читаются как текст. Не исполнять target. Не читать/передавать private config/certs/inputs/materials/references/runs, ключи или credential-location; task-local явно допущенные исходники/результаты — отдельный разрешённый объём. Не менять корпоративную сеть, credentials, ledger/history/unknown-reserves, старые результаты/ZIP; без commit/push/deploy/global memories. Платный запуск требует актуального прямого поручения и штатных guard. Browser file-policy block не обходить.
