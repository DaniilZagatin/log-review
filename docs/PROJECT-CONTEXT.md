# Контекст полного продукта

Актуально: 30 октября 2026. Папка `full-agent-test` содержит продукт для постановки варианта сценария процесса на учёт.

## Общий поток

Вход: описание варианта и один или несколько каталогов/ZIP с исходниками. Белка создаёт карту действий и бизнес-операций. Рашид читает ту же зафиксированную версию исходников, сопоставляет логи с действиями, показывает C/P/U/X и адресные доработки. Метрики связывают определения и требования к данным с картой, существующими записями и предложенными изменениями.

Выход: один автономный HTML с вкладками «Карта», «Логирование», «Доработки», «Метрики», структурированные результаты и manifest запуска. Состояние выполнения отделено от структурной допустимости, покрытия и семантической приёмки.

## Границы

Единственный построитель карты — Белка в `src/pko`. Рашид не создаёт второй граф. Удалённый альтернативный pipeline доступен в истории Git и не является резервным режимом продукта. Возобновление и запуск с готовой карты используют тот же общий поток.

Наблюдаемые бизнес-значения метрик не вычисляются по статическому коду. Запрос не доказывает результат; присутствие логирования не доказывает доставку записи. Предлагаемые доработки не повышают C. X не означает отсутствие логов. Частичная карта ограничивает выводы всего продукта.

## Разработка

План и критерии: `plans/full-product-integration.md`. API этапов и общий запуск проверяются синтетическими offline-тестами; живой ограниченный прогон и оценка специалистом нужны для семантической приёмки. Инструкция запуска находится в README. Импорт Белки фиксирует исходную ревизию, а сборка из этой папки не требует соседнего checkout.

Документы старых экспериментов и Q/CREDIT-запусков сохраняют контекст своей поставки. Указанные там бюджеты, процессы и договорённости не описывают текущий локальный запуск.
