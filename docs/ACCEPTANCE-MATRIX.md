Сценарии не удалены и не ослаблены: то, что требует записей выполнения, истории состояний, внешних справочников или методики, отмечено как находящееся **вне текущей приёмки**.

Автор реализации тесты не запускал; зелёный прогон не означает проверки живой модели или runtime-сценариев, отмеченных ниже как отложенные.

## Виды проверок

| Вид | Что доказывает | Чего не доказывает |
|---|---|---|
| **Контракт** | Недопустимое состояние нельзя создать, сериализовать или принять из ответа модели | Что конвейер когда-либо формирует допустимое состояние правильно |
| **Конвейер** | `run_analysis`/CLI со сценарными ответами модели и подменённым HTTP формирует или не допускает конкретный результат | Качество ответов живой модели |
| **Отображение** | HTML, Markdown или пакет экспорта показывают и экранируют данные артефактов, не пересчитывая их | Правильность самих данных |
| **Качество модели** | — не проводилась: сценарные ответы проверяют защитные механизмы, а не смысловую точность GLM/DeepSeek | |
| **Корпоративная проверка** | — не проводилась: реальная репа, доступность моделей, TLS handshake, Windows, установка wheel | |

Состояния строк: **принято по исходникам** — применимая к текущему входу часть закреплена указанными тестами; **частично** — закреплена часть по исходникам, остальное вне приёмки; **вне текущей приёмки** — нужны входы, которых нет. Наличие enum или поля контракта само по себе не считается пройденным сценарием.

Имена тестов: `файл::метод` в каталоге `tests/`.

## Проверки экспорта C1

`tests/test_onboarding_export.py` использует запуски, записанные настоящей командой `demo`; варианты заменяют только записанные ответы модели. Проверяются: совпадение артефактов, ID, evidence и снимка с исходным запуском без вызова модели, чтения репы и изменения запуска; обязательный этап и операция без кода; различие найденных и предложенных событий, отсутствие событий из `join`/`enrich`/`map_existing` и из текста описаний; обратимое кодирование CSV и защита от формул; экранирование Markdown, HTML и ссылок; частичные запуски без неполных CSV; отклонение висячих ссылок, расхождения копий, повторяющихся ключей, `NaN`, чужого снимка, значения метрики, symlink, путей внутрь запуска и существующих каталогов; удаление при сбое записи только созданных файлов; повторяемость. `tests/test_cli.py` проверяет команду, код выхода 0/1/2 и запрет перезаписи.

## Что остаётся вне приёмки по исходникам

- Расчёты по фактическим записям: возможности выполнения, группировка попыток и доставок, соединения, длительности, когорты, качество поставки (E02–E10, E16, E19 в части данных). Это шаги S05–S08 исходного плана; для пилота по исходникам они не обязательны и требуют логов, истории или справочников.
- Конфликт с принятым контрактом канала и доверенные решения (E12): нет принятого контракта и подключённого входа решений.
- Качество живой модели: полнота карты, верность привязок, отсутствие выдуманных утверждений в тексте.
- Корпоративная проверка: реальная репа, GLM-5.3 и DeepSeek-V4-Flash в корпоративной сети, TLS handshake, Windows и установка пакета.
- Отображение в браузере для этого шага не повторялось; у экспорта нет HTML. Прежние браузерные проверки HTML описаны в `docs/STATUS.md` как история.
