Порядок старта новой сессии: `AGENTS.md` → краткий `docs/STATUS.md` → текущий контекст и план. Исторические handoff/статус/контекст сохранены в `.local/context-history-20261029/`; не загружать их по умолчанию. Старый чат не является обязательным входом.

При переносе кода сначала проверить зависимости и протоколы, затем перенести минимальный фрагмент и его значимые проверки. Снимки в `references/pko/` не входят в пакет приложения. Файлы в `materials/private/` нельзя исполнять или автоматически загружать во внешние сервисы.
