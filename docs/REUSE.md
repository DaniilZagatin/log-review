# Минимальное переиспользование PKO

Исходный проект: `/Users/jlocehok/Downloads/Telegram Desktop/PASSPORTNEEEEEW`.
Снимки выбранных файлов сохранены в `references/pko/`; контрольные суммы — в реестре источников. Эти файлы ещё не перенесены в рабочий пакет.

| Кандидат | Решение при реализации |
|---|---|
| `progress/agent_tools.py::ToolBox` | Перенести list/read/search и необходимые ограничения. Типовые зависимости Tree/Extraction заменить узкими протоколами; facts/who_calls подключать явно |
| `progress/review_evidence.py::verify_observations` | Переиспользовать проверку диапазонов и извлечение цитат; сохранять основание и ревизию. Структурный гейт не доказывает смысловую истинность |
| `extractors/base.py::FileTree`, `Fact` | Взять минимальный контракт чтения и факта, убрать зависимость от готовности PKO |
| `extractors/python_code.py` | Адаптировать объявления/вызовы для первого Python-примера. Отдельно извлекать log calls до фильтра собственных вызовов; учитывать неоднозначность коротких имён |
| `progress/target_scenarios.py` и промпт | Адаптировать подход «бизнес-сценарии до сопоставления с кодом», не переносить стандарт/каталог PKO целиком |
| `progress/passport_graph.py` и промпт | Использовать идеи привязок и сохранения обязательных шагов; объектная модель BBB не является обязательным контрактом нового агента |

Прямой импорт текущего ToolBox подтягивает 21 модуль примерно на 4 тыс. строк. Поэтому перенос должен отделить интерфейсы от общего runner экстракторов. Это оценка статической замкнутости импортов, не готовый размер нового ядра.

Проверено 26 октября 2026 года: 10 локальных проверок на искусственном примере прошли с `python3 -B -S`, без сети, LLM и сторонних пакетов. Проверялись чтение/поиск, ссылки на вызовы, запрет секретных/внешних путей, ошибки разбора, извлечение/отклонение цитат, сохранение unknown в знаменателе и строковый HTML-рендер. Полный набор тестов PKO не запускался.

Критические ограничения: граф вызовов приблизительный и отбрасывает внешние вызовы вроде logger.info; `Extraction.coverage` — покрытие разбора исходников, не логов процесса; готовый граф паспорта строится по предыдущей оценке и не является готовым source-to-process miner.

Готовый HTML паспорта можно рассмотреть позже. Для первого прохода достаточно JSON и читаемого отчёта. Лицензионный файл в корне предоставленной копии PKO не найден; происхождение каждого перенесённого файла сохранять, условия внешнего распространения не считать установленными.
