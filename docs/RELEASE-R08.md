# R08 — детализация и карточка операции

Самостоятельная полная версия для пустого каталога; предыдущие архивы и патчи не нужны. Старые поставки не изменены. В архив входят код, инструкции и синтетические примеры; ключи, сертификаты, целевые исходники, бизнес-вход, ledger и реальные результаты анализа не включаются.

Реализованы уровни «Процесс → Этапы → Операции», структурные метаданные операции в той же небольшой атомарной странице, точные связи с логами/фактами/доработками, адресные вопросы, структурные пути с циклами, полный раскрываемый код. Условие неизвестного перехода не выдумывается; API-команда не считается кликом, исходящий запрос — результатом получателя. Метки по совпадению ключа или места в коде остаются кандидатами.

Offline-проверка:558 tests без ошибок и пропусков в чистом каталоге, неизменённое строгое записанное demo и export, отрицательные проверки nested DTO/источников/одинаковых ключей/общих helpers/устаревших подтверждений. Браузерная проверка синтетического отчёта на1440/768/375px: русский шрифт, CSP, консоль, переключатели, карточки и внутренние ссылки. Это не доказывает качество живой модели.

`evaluate-map` сравнивает только область явно ручной разметки, связывая вывод с map/source/oracle hashes. Пересечения диапазонов — кандидаты, а не доказанная семантика. Реальной ручной разметки нового целевого приложения не предоставлено; тестовый oracle синтетический. Необязательные подсказки о склейках эвристические.

Базовая реализация прошла взаимное ревью. Первый свежий реальный анализ завершился частично: карта/покрытие/доработки сформированы, запрос метрик вернул пустой ответ; две атомарные страницы отклонены. Независимая сверка также обнаружила неверную связь запуска робота с началом работы сотрудника. Исправление и окончательная приёмка продолжаются; полный R08ZIP ещё не выпущен. Финальный статус четырёх стадий будет записан перед выпуском. Наблюдаемых runtime-логов нет: численные метрики не заявляются; исторические числа бизнес-документа не становятся новыми измерениями.
