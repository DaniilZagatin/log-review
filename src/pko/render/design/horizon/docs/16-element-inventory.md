# Каталог элементов

Каждый элемент, замеченный в референсах, и где он живёт в системе.

| Элемент в референсе | Что это | Компонент / стиль |
|---|---|---|
| Огромная строка поиска и чипы-подсказки (Яндекс Работа) | Текст 56px без поля, лупа 40px, ниже чипы lg | `SearchField size="hero"`, `Chip size="lg"` |
| Пилюля-фильтр «Статус: Все» | Серая пилюля с зелёным значением | `FilterPill`, `FilterBar` |
| Карточка списка с превью (Runway) | Серая плитка, превью, подпись | `FeatureTile`, `MediaCard` |
| Кадр видео «Seedance 2.0» | Тёмный кадр, название, панель | `VideoFrame` |
| Дашборд «Overview» | Показатели, столбцы, список, полосы | `PatternDashboard`, `StatCard`, `BarChart`, `ListRow`, `ProgressBar` |
| Лендинг мебельного магазина | Большой заголовок, плитки, воздух | `PatternLanding`, `Hero`, `MediaCard` |
| Плавающие иконки приложений в герое | Кластер суперэллипсов | `AppIcon`, `PatternGallery` |
| Мега-меню на четыре колонки | Серые заголовки, крупные ссылки | `MegaMenu` |
| Большой список «Финансовые приложения» | Активная строка чёрная, остальные серые | `OptionGroup variant="list"`, `ShowcaseTabs` |
| iOS / Web | Серый лоток с белым сегментом | `SegmentedControl` |
| Вкладка «Latest» | Текст с подчёркиванием | `Tabs underline` |
| Экраны телефонов без рамок | Цветные сцены, экран обрезан снизу | `Stage`, `PhoneScreen`, `ScreenCard` |
| Тёмная cookie-пилюля | Плавающая, две кнопки | `CookieBanner` |
| Серая строка с BETA | Контурный тег, текст, ссылка | `InfoBar`, `Badge mono` |
| Карточка запроса с копированием | Контур, текст, иконки внизу | `PromptCard` |
| Сетка «подключить инструменты» | Серые кнопки иконка + имя | `ToolTile` |
| Чат с мерцанием «Gathering insights» | Пузырь пользователя, ответ без пузыря | `Message` |
| Монитор «Patient Monitoring» | Окно на сцене-дымке | `AppWindow crop`, `PatternMonitor` |
| Верхняя панель с пилюлями | Чёрная активная пилюля | `AppWindow nav` |
| Рейка круглых иконок | Активная зелёная | `AppWindow rail`, `SideNav collapsed` |
| Таблица на сером лотке | Белая строка заголовка | `Table` |
| Статусы Okey / Pending / Alert | Мягкие пилюли | `StatusPill` |
| Штриховые полосы | Диагональная штриховка | `ProgressBar tone="hatched"` |
| Лёгкие цифры с серой единицей | Вес 300 | `Metric` |
| Круглая ⓘ | Кнопка-пояснение | `IconButton icon="info"` |
| Пунктирная линия процесса | Этапы, узлы-пилюли, теги | `ProcessTimeline` |
| Линейный график лавандой | Пунктирная сетка, пустые маркеры | `LineChart` |
| Кольцо с итогом | Округлые сегменты | `Donut` |
| Вопрос ассистента с вариантами «1–4», «Другое», «Пропустить» | Карточка радиусом 28, зелёная рамка выбранного, поле «Или ответьте напрямую…» | `ClarifyCard` |
| Правая панель «Прогресс» с рейкой этапов | Серые завершённые, активный чёрный с точкой | `SidePanel`, `ProgressSteps` |
| Карточка результата «Артефакт» | Плитка с предпросмотром, название и тип | `ArtifactCard` |
| «Использовано в этой сессии» | Иконка, подпись, значение, «+18» | `UsageRow` |
| «Контекст»: Использовано 84 % | Полоса и легенда с цветными квадратами | `ContextMeter` |
| Ответ-план с калькулятором и чек-листом | Серая карточка, белые блоки | `AnswerCard`, `QuantityScaler`, `ChecklistTimeline` |
| Индикатор «нейросеть думает» | Точечный шар | `ThinkingOrb`, `ThinkingStatus` |
| Маскот-подсказка | СберКот с плашкой | `Mascot`, `MascotHint` |
| Страничные приёмы воздуха | Рамки радиуса 48 | `hz-frame`, `Haze`, `CTABand` |

Чего в референсах нет, а в системе есть (намеренное дополнение для огромного сайта): формы (`Field`, `Input`, `Select`, `Checkbox`, `Radio`, `Switch`, `Slider`, `Stepper`, `Dropzone`), оверлеи (`Modal`, `Drawer`, `Toast`, `Alert`, `Tooltip`, `Menu`), контент (`Accordion`, `Timeline`, `Testimonial`, `Rating`, `CodeBlock`, `PricingCard`, `Steps`, `LogoCloud`, `Pagination`, `Breadcrumbs`, `EmptyState`).

Страницы, которые не удалось открыть при подготовке (Mobbin Flodesk и Mobbin MCP — доступ закрыт, Behance — только картинки), восстановлены по присланным скриншотам; если их стиль отличается, пришлите ещё экраны.
