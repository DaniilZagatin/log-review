# Таблицы и статусы

Стиль таблицы задаёт серый лоток: плотные данные выглядят спокойно.

## Таблица (`Table`)

- Основание: лоток `bg-subtle` радиусом 24 с внутренним отступом 8.
- Заголовок — отдельная белая строка (`bg-raised`) радиусом 16, текст 14px `ink-secondary`, без капса и без вертикальных линий.
- Строки: высота по `density` (`sm` 8, `md` 16, `lg` 24 вертикального отступа), разделитель 1px `line-hairline`, у последней нет. Наведение или выбор — `bg-muted`.
- Колонки: имя и аватар слева, категория, статус слева, график-спарклайн, числа справа табличными цифрами, действия-иконки в последней колонке.
- `variant="plain"` — без лотка, на белом, с линией под заголовком. Для вложенных таблиц внутри карточек.

## Статус-пилюли (`StatusPill`)

Высота 28, отступ 14, текст 14/500, мягкая заливка без рамки:

| Статус | Фон / текст | Слово |
|---|---|---|
| `ok` | `success-soft` / `success` | Норма |
| `pending` | `info-soft` / `info` | В ожидании |
| `alert` | `danger-soft` / `danger` | Тревога |
| `draft` | `warning-soft` / `warning` | Черновик |
| `neutral` | `bg-muted` / `ink-secondary` | — |

Слово обязательно; точку (`dot`) добавляйте, когда пилюля стоит отдельно от таблицы. Не изобретайте новые статусы: сводите к этим пяти.

## Метки и бейджи

`Badge` — 24px: `neutral`, `accent`, `success`, `warning`, `danger`, `info`, `outline`, `inverse`; моно-вариант для BETA/NEW. Контурный `BETA` стоит слева в серой `InfoBar`.

## Круглые «ⓘ»

Рядом с заголовком показателя — `IconButton icon="info" variant="ghost" size="sm"`: пояснение открывается подсказкой или поповером.

## Пустая таблица

`EmptyState` в границах лотка: иконка, одна фраза, одно действие.
