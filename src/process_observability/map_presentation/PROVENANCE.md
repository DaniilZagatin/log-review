# Происхождение отображения карты полного продукта

`scenario_map.py` — адаптер карты Белки для единого автономного HTML. Он сохраняет API `scenario_map_parts`, слой покрытия C/P/U/X, встроенные вкладки и адресные переходы к действиям. Это интеграционный модуль; он уже не является копией, отличающейся только импортами.

Актуальный движок Белки расположен в `src/pko`; исходная импортированная ревизия и хеши — в `docs/belka-import.json`. Из текущего renderer `pko.render.scenario_map` адаптер использует общие правила терминологии действий и отображения сводки. Он также сохраняет `outcome_scope=shared` как нейтральное завершение и показывает границу бизнес-операции. Изменения визуальной семантики следует проверять в обоих представлениях.

`compat.py` использует общий `pko.stages.inputs.map_revision`. Для `variant-actions-v1` группировка проверяется validator Белки; для карт без профиля явно сохранены прежние проверки отображения. Карта не получает новую семантику автоматически.

`theme.py` и ресурсы `assets/dpss`, `assets/horizon` сохраняют автономные шрифты и стили. Упаковка должна включать их вместе с ресурсами pko. Входной HTML не читается и не исполняется: весь отчёт строится из проверенных JSON-артефактов.

При обновлении Белки переносить изменения предметной семантики и проверки в адаптер с сохранением API вкладок/overlay. Автоматическая замена файла только по правилам старого re-vendoring недопустима. Проверять реальные исходы, циклы, условия, бизнес-операции, shared-финализатор и переходы между вкладками.
